📋 5 Langkah Cepat Transaksi Kasir:

1. Awal Shift: Input modal awal kasir sebelum melayani pembeli.

2. Scan Produk: Arahkan barcode ke pemindai atau ketik nama pada live search.

3. Input Member: Tekan F4 atau tombol member jika ada kartu/nomor HP pelanggan.

4. Pembayaran [F1]: Pilih Tunai, QRIS, atau Transfer, lalu input uang diterima.

5. Akhir Shift [F11]: Hitung fisik uang kasir, lakukan closing klerk, cetak struk rekap.
