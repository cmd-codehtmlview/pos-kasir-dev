Panduan Koneksi Printer VSC Mini Thermal Solusi Lengkap

Cara mudah cetak ke printer VSC (MP-58M, TM-58, POS-58) di Komputer & HP Android

🌟 Solusi 1: Pakai Kabel USB Paling Stabil di PC / Laptop

Printer VSC mini thermal selalu menyertakan kabel USB di dalam dus kemasannya. Colokkan kabel USB ke port laptop/PC kasir dan nyalakan printer. Cetak kabel USB tidak memerlukan baterai, tidak delay, dan 100% stabil untuk transaksi toko yang padat.

💻 Solusi 2: Aktifkan Bluetooth di Google Chrome (PC / Laptop)

Pada sistem operasi Linux (seperti Linux Mint) dan sebagian desktop, Google Chrome menonaktifkan fitur Web Bluetooth secara default. Anda dapat mengaktifkannya hanya dalam 1 menit:

  1. Buka tab baru di browser Google Chrome Anda.
  2. Ketik atau tempel alamat flag berikut di address bar Chrome:
    chrome://flags/#enable-web-bluetooth
  3. Ubah status opsi Web Bluetooth dari Default menjadi Enabled.
  4. Klik tombol biru Relaunch di pojok kanan bawah Google Chrome.
  5. Buka kembali kasir dan klik tombol "Hubungkan Bluetooth"!

📱 Solusi 3: Menggunakan HP / Tablet Android

Jika melayani transaksi menggunakan HP Android atau tablet kasir:

  • Buka Google Chrome di HP Android dan buka URL server kasir (misal: http://192.168.x.x:8080).
  • Untuk VSC tipe BLE (Bluetooth 4.0+): Klik tombol "Hubungkan Bluetooth", HP akan langsung memunculkan menu pairing perangkat.
  • Untuk VSC tipe Bluetooth Classic (2.0/3.0): Download aplikasi gratis RawBT Print Service di Play Store, lalu di SnackPOS pilih mode "Jembatan RawBT Android".
