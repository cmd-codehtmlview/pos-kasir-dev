  • ✓ Printer Thermal: Auto-connect Bluetooth 58mm & 80mm.

💡 Cara Pasang di HP / Tablet:
  1. Tekan tombol merah di atas untuk mengunduh SnackPOS.apk.
  2. Jika muncul notifikasi "File mungkin berbahaya", pilih Tetap Download.
  3. Buka file yang telah selesai diunduh, lalu tekan Instal.
  4. Buka aplikasi SnackPOS dan langsung gunakan untuk operasional kasir.
